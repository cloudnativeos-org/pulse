Numbered citations, the source list they point to, and the "Data as of" stamp.

**Provide:** a profile source (`url`, `title`, `type`, `retrieved`).

**Citation:** a superscript `[n]` linking to `#src-n`. Several sources: `[3,4]`. Numbers follow the order of first use on the page.

**Source list:** title linked to the URL, then the project, the source type and the retrieval date. In print the full URL is printed under each item.

**Data as of stamp:** a bordered inline block, "Data as of 22 Sep 2026", followed by the collection and re-verification dates. In print the same date runs in the page header.

**Don't** cite a marketing comparison page, or link to a private repository.
