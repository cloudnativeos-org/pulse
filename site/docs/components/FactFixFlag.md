A review marker on a cell whose wording is under fact-check.

**Provide:** a short neutral note (what the source does and does not say).

**Variants**
- Tag only: `! Fact-fix` or `! Newer release`, note in the tooltip. Use in the entry column.
- Tag plus note: the note prints below on `flag-bg`. Use in value cells.

The flag uses the only tint in the system (`flag-bg`, `flag-ink`, `flag-rule`). It marks review state, never a judgement on a project. It is dropped from the public build once the fix lands.
