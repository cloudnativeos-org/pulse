A question block for one kind of reader. It lists the questions that decide a choice and routes each to a matrix filter or a dimension. It never names a project.

**Provide:** a reader description in the reader's terms ("If you run machines at many remote sites over weak links"), four to six questions, and for each a route: `Matrix` (a filter or column URL) or `Dimension` (an anchor).

**Do** phrase questions as the reader would ask them. Use routes that already exist; if a question has no column yet, route to the dimension only.

**Don't** write "best for", "choose", "recommended", or any project name. Methodology section 8 needs an amendment that allows this block.
